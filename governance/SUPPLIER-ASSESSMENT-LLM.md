# Supplier assessment: external LLM API provider (A.10.2, A.10.3)

| Area | Finding | Result |
|---|---|---|
| Security certification | ISO/IEC 27001 certificate and SOC 2 Type II report reviewed | Accepted |
| Data use | Contract: prompts and outputs not used for supplier training | Accepted |
| Data residency | Processing region contractually fixed | Accepted |
| Incident notification | Supplier notifies within 72 hours of a security incident | Accepted |
| Model changes | 30-day notice before model version retirement | Accepted with monitoring |

## Allocation of responsibilities
The supplier secures the model and its hosting. Meridian is responsible for the prompts,
tool permissions, input and output guardrails, monitoring, and customer communication.
